# BrickTally

The installer is not signed. That is expected.

1. Download BrickTallySetup.exe: https://github.com/NEXUS-Systems-Core/bricktally/releases/latest/download/BrickTallySetup.exe
2. Double-click BrickTallySetup.exe.
3. If Windows shows a blue SmartScreen box, click More info, then Run anyway. The app is unsigned.
4. Open BrickTally from the desktop icon.
5. Updates appear inside the app.
